## 📋 Descripción del proyecto

Este portafolio personal tiene como objetivo presentar mi perfil
académico y profesional, mis habilidades y algunos de los proyectos
en los que he trabajado.

La primera versión fue desarrollada utilizando HTML y CSS.

Para la Actividad Integradora 2 se incorporó JavaScript para agregar
interactividad y funcionalidades dinámicas al sitio.

---

## 🆕 Funcionalidades agregadas en la Actividad Integradora 2

### JavaScript

Se incorporó un archivo externo llamado:

```text
script.js
````

El archivo contiene las funcionalidades interactivas del portafolio.

### Eventos

Se utilizaron eventos mediante `addEventListener()`, entre ellos:

* `click`
* `input`
* `submit`
* `scroll`

### Manipulación del DOM

JavaScript modifica dinámicamente diferentes elementos del sitio.

Entre las modificaciones realizadas se encuentran:

* Cambio del mensaje de bienvenida.
* Cambio del texto del botón de modo oscuro.
* Mostrar y ocultar información adicional.
* Mostrar mensajes de validación del formulario.
* Mostrar fecha y hora actual.
* Crear y mostrar el botón para volver al inicio.

### Validación del formulario

El formulario de contacto verifica que los siguientes campos
no estén vacíos:

* Nombre.
* Correo electrónico.
* Mensaje.

Si existe algún campo vacío se muestra un mensaje de error.

Cuando todos los campos están completos se muestra un mensaje
de confirmación.

### Modo oscuro

Se agregó un botón que permite cambiar entre modo claro y modo oscuro.

La selección del usuario se guarda mediante `localStorage`.

### LocalStorage

Se utiliza `localStorage` para almacenar:

* La preferencia del tema.
* El nombre del visitante.

Los datos almacenados se recuperan posteriormente y se utilizan
para modificar visualmente el contenido del portafolio.

De esta manera, la información permanece después de recargar
la página.

### Fecha y hora

JavaScript muestra dinámicamente la fecha y hora actual.

### Botón volver al inicio

Al desplazarse por la página aparece un botón que permite regresar
al inicio utilizando un desplazamiento suave.
