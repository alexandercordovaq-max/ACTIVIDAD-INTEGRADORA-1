## Descripción

Este proyecto corresponde al desarrollo de un portafolio personal
utilizando HTML5 y CSS3.

El sitio web presenta información personal, formación académica,
habilidades, proyectos y una sección de contacto.

El objetivo del proyecto es demostrar conocimientos básicos de
desarrollo web, estructura HTML, estilos CSS y utilización de Git
y GitHub para el control de versiones.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
